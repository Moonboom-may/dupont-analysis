# 杜邦分析 · 经营诊断引擎

一个**完全本地运行**的杜邦分析与经营诊断网页应用：上传 `.docx` 财务报表（或一键载入典型样本），自动完成平衡校验、三因素杜邦拆解、经营风险评级，并一键导出排版精美的 Word 诊断报告。

> 🔒 所有数据仅在浏览器本地处理，不上传任何服务器；新建分析时通过二次确认彻底清除上一轮数据。

## ✨ 功能特性

### 一、Word(.docx) 报表本地解析引擎
- **多文件 / 单文件**：支持上传单个含三张表的 `.docx`，或分别上传资产负债表、利润表、现金流量表（最多 3 个文件）。
- **自动识别**：识别企业名称、报告期间、金额单位（元 / 万元 / 亿元）及资产总计、负债、所有者权益、营收、净利润、经营现金流等核心科目。
- **平衡与勾稽校验**：自动校验 `资产 = 负债 + 所有者权益`，**差额超过 0.5% 自动阻断**并提示。

### 二、三因素杜邦分析拆解图
- **三级树状结构**：顶层 ROE 拆解为销售净利率 × 总资产周转率 × 权益乘数，底层关联净利润 / 营收 / 总资产 / 净资产明细。
- **驱动归因与评级**：自动判断驱动模式 —— 高利润率驱动型 / 高周转薄利驱动型 / 高财务杠杆放大驱动型 / 亏损主导，并对过高杠杆提供风险预警。
- **交互式探查**：点击任意指标节点展开计算公式与管理解释。

### 三、经营诊断报告与风险评级
- **三级综合评级**：依据盈利、现金流造血、周转、杠杆四维度客观评定为 **优秀 / 正常 / 风险**。
- **标准化报告全结构**：①封面与综合评级 ②执行摘要 ③14 项核心指标概览 ④盈利/偿债/营运/现金流四维度诊断 ⑤风险提示与改善建议（高/中/低优先级，结构化呈现问题、数据依据、影响、对策）⑥数据口径与免责声明。
- **AI 智能经营顾问**：基于已校验指标自动生成严谨客观的高管层复盘洞察（总体判断 / 主要优势 / 主要风险 / 优先建议）。

### 四、Word 报告导出与隐私生命周期
- **一键导出 .docx**：本地生成排版精美的诊断报告，支持本地下载保存。
- **单次会话临时处理**：新建分析时通过**安全二次确认弹窗**彻底清除上一轮原始文档与分析数据。
- **内置典型样本**：预置高科技制造（优秀）、供应链商贸（正常）、重工建设（风险）三类真实典型场景，一键载入快速测算。

## 🚀 使用方法

### 方式一：直接打开
双击 `index.html` 用现代浏览器（Chrome / Edge 80+ / Firefox 113+）打开即可。

> ⚠️ 建议用本地服务器打开以避免某些浏览器的 file:// 限制：

```powershell
# PowerShell（需 Python 3）
cd C:\Users\cuimingyue.15\Desktop\dupont-analysis
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

### 操作流程
1. **载入数据**：上传 `.docx`（单文件或分表），或点击底部典型样本卡片一键载入。
2. **解析校验**：点击「开始解析与校验」→ 自动完成平衡校验与科目抽取。
3. **杜邦拆解**：查看三级树状图与驱动归因，点击节点探查明细。
4. **经营诊断**：查看综合评级、14 项核心指标、四维度诊断、风险清单；按需生成 AI 洞察。
5. **导出报告**：一键导出 Word 诊断报告；新建分析时确认清除数据。

## 🔧 技术说明

- **零后端**：纯前端 HTML + CSS + 原生 JS，无构建步骤、无框架依赖。
- **读取 .docx**：使用 JSZip 解压并解析 `word/document.xml`，提取表格文本与科目。
- **导出 .docx**：手写 OOXML（`word/document.xml` 等 5 个部件），用浏览器原生 `CompressionStream("deflate-raw")` 打包为标准 ZIP，无需任何第三方 docx 库，生成文件经 Microsoft Word 实测可正常打开。
- **隐私**：所有解析、计算、生成均在浏览器内存中完成；不发起任何网络请求；新建分析时二次确认后清空全部状态。
